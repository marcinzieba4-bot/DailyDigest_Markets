# 2026-06-24 — archive page built from the original report, in the current format

The report of Wednesday 2026-06-24 (generated by the Lambda at 17:17 UTC) existed only as `Strategies/json` + PDF:
static HTML publishing started on 06-25, so it had no `reports/archive/` page and none of the archive corrections.
It now has both. Everything was written as of 2026-06-24 with the data available then.

## How it was built (layers, in order)
1. **Original, rebuilt** — `rebuilt_original.html` from `source/2026-06-24_Market_Intelligence.json` (the untouched
   original) by `tools/reconstruct.py`, in the Lambda's template of the time (06-25 original as reference). Check:
   the Lambda's `_parse_html_paragraphs()` on the rebuild returns the JSON's 48 subheadings and 122 paragraphs exactly
   (`tools/roundtrip.py`); the same method rebuilds 06-25 with only mid-paragraph `<em>`/`<strong>` emphasis missing.
2. **US Treasury yields** (the 2026-10-19 fix) — `cards/yield_2026-06-24.json` by `tools/card_yield.py` (same logic as
   `corrections/2026-10-19/cards.py`; it reproduces the stored 06-25 card exactly). Official closes of 06-23 (2Y 4.16%,
   10Y 4.50%, 10Y-2Y +34 bps, 9 bps flatter vs 4W) and the live 10Y the report quoted (4.41%, −8 bps vs 4W) replace the
   13-week-bill "2Y 3.69%", the "+72bps" spread and the percent-of-yield moves. Edits: `yield_edits.json`.
3. **Wide Poland block** — `poland/new.html` from `poland/feed_2026-06-24.json` (cut-off 17:00 UTC on 06-24) and
   `cards/poland_2026-06-24.json` (06-23 closes), checked by the Poland pass's `verify_pl.py` (PASS, no WARN).
   Stricter than the earlier pass: items dated 06-24 carry Google's nominal 07:00 time, so only those clearly published
   before 17:00 UTC (the 15:00 UTC Warsaw close, morning releases) were used; rolling pages were excluded.
   `pre_china.html` = layers 1–3 (= `corrections/china/orig/2026-06-24.html`).
4. **China block, copper / gold, four-part sectors, Earnings Pattern** — the usual `corrections/china` pass:
   `new/`, `edits/`, `sectors/`, `pattern/2026-06-24.*` on feeds dated strictly before 06-24 (`feeds/`, `feeds_earn/`,
   `feeds_earn_prev/`). `final_check.sh 2026-06-24`: cn / report / sectors / pattern PASS (0 warn), 0 unmatched cites;
   the Lambda's `compliance_issues()` reports nothing.

Time discipline: no tag later than Jun 23 except six Jun 24 Poland items (session close / morning data); misdated feed
items (e.g. a "July payrolls preview" dated Jun 8, ad-hoc-news "third-quarter results" dated Jun 10, a "June ISM" dated
Jun 7) were dropped; Micron (reporting after the US close on 06-24) appears only through previews.

Note on the earlier Poland cards (06-25 …): they took the FX "prior close" from Yahoo's candle stamped 23:00 UTC of the
previous day, which is the London candle of the report day itself — USD/PLN and EUR/PLN there are the report day's
own close (a few hours after 17:00 UTC). Equities and EPOL are unaffected. Here the 06-23 London candle is used.

`data/` holds the downloaded Treasury par curve (2026) and Yahoo daily closes; the cards use only values dated before
06-24. Published with `corrections/china/tools/upload.py 2026-06-24 --go` plus an `index.html` row.
